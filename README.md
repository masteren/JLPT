# 日语 N1 真题刷题记录

1992-2025 年 N1 / 一级历年真题，以及我自己的作答、错题笔记和考点积累。

## 目录结构

```
题/                 真题与解析 PDF（.gitignore 忽略，不入库）
答题卡/             我的原始作答，一场一个文件
错题笔记/           逐题订正 + 考点讲解，一场一个文件
  _模板.md          新建笔记时复制这个
积累/               跨套卷累积的考点清单 —— 复习时主要看这两份
  易错词汇.md
  易错语法.md
工具/               读 PDF 的脚本（见 工具/README.md）
```

`题/` 里的 PDF 不入库：体积大，而且是尚岸日语的版权材料。
换机器后把 `题/` 文件夹拷过去即可，其余内容都在 git 里。

## 怎么用

1. 做完一套，把答案按大題分组写进 `答题卡/YYYY-MM.md`
2. 对答案 —— 答案在对应的 `题/.../【2】…答案解析….pdf` 里
3. 复制 `错题笔记/_模板.md` 到 `错题笔记/YYYY-MM.md`，逐题订正
4. 把**考点**（不是整题）抄进 `积累/` 的两份清单，标上出处
5. 更新下面的进度表

复习时只翻 `积累/` 两份清单，错题笔记是查证用的。

## 答题卡格式

按大題编号分组，一行一个答案：

```
1.
4
2
4
3
1
1

2.
3
2
...
```

`1.` `2.` … 对应 問題1、問題2 …（不是题号）。

## N1 题型与题号对照

| 大題 | 题号 | 内容 |
| --- | --- | --- |
| 問題1 | 1-6 | 漢字読み |
| 問題2 | 7-13 | 文脈規定 |
| 問題3 | 14-19 | 言い換え類義 |
| 問題4 | 20-25 | 用法 |
| 問題5 | 26-35 | 文法形式の判断 |
| 問題6 | 36-40 | 文の組み立て（★题） |
| 問題7 | 41-45 | 文章の文法 |
| 問題8-13 | 46-71 | 読解 |
| 聴解 問題1-5 | — | 課題理解 / ポイント理解 / 概要理解 / 即時応答 / 統合理解 |

2010 年起为现行 N1 题型；2009 年 12 月及以前是旧「一級」，题型不同。
