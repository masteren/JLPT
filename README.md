# 日语 N1 真题刷题记录

2010-2020 年 N1 历年真题（21 场），以及我自己的作答、错题笔记和考点积累。

> **错题本（网页，私有链接，仅本人可访问）**：<https://claude.ai/artifact/Y2uW6UvL6vZw3mfGwjtD8K>
> 50 道错题，答案默认盖着，重选一遍才揭晓讲解。可按场次 / 题型 / 病因筛选。
> 内容全部来自 `错题笔记/` 和 `积累/`，这两个目录才是源头。

## 目录结构

```
题/          真题与解析 PDF（.gitignore 忽略，不入库）
答题卡/      我的原始作答，一场一个文件
答案/        预取好的参考答案，一场一个文件
错题笔记/    逐题订正 + 考点讲解，一场一个文件（_模板.md 是新建时复制的）
积累/        跨套卷累积的考点清单 —— 复习时主要看这两份
工具/        读 PDF 的脚本，见 工具/README.md
```

`题/` 不入库：体积大（362 MB），而且是尚岸日语的版权材料。
换机器时把这个文件夹拷过去即可，其余都在 git 里。

## 怎么用

1. 做完一套，把答案按大題分组写进 `答题卡/YYYY-MM.md`
2. 对答案 —— 先看 `答案/YYYY-MM.md`；没有的场次从 `题/.../【2】…答案解析…-版本1.pdf` 第 1 页取
3. 复制 `错题笔记/_模板.md` 到 `错题笔记/YYYY-MM.md`，逐题订正
4. 把**考点**（不是整题）抄进 `积累/` 两份清单，标上出处
5. 更新下面的进度表

复习时只翻 `积累/` 两份清单和网页错题本，错题笔记是查证用的。

## 答题卡格式

按大題编号分组（`1.` `2.` … 对应 問題1、問題2，不是题号），一行一个答案：

```
1.
4
2
4

2.
3
2
```
